# ret_ImmersiveScreen

One key for a clean cinematic frame in World of Warcraft.

ret_ImmersiveScreen hides the interface like Alt+Z, also hides the names that Alt+Z
leaves on screen, and adds cinematic Letterbox bars. Made for screenshots and for
simply enjoying the world.

The same files work in WoW Retail and WoW Forever.

> **Status:** early development, nothing is released yet.

## Installation

Copy the `ret_ImmersiveScreen` folder into your client's `Interface/AddOns` folder:

- Retail: `_retail_/Interface/AddOns/ret_ImmersiveScreen/`
- Forever: `_forever_/Interface/AddOns/ret_ImmersiveScreen/`

## Commands

- `/retis` or `/retimmersivescreen` — show the addon version.
